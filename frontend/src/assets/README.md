# Photography pipeline

Originals live outside the repo. Supplied Windows paths:
- `C:\rabta-assets\hero\hero-original.jpg`
- `C:\rabta-assets\hero\hero-alt-1.jpg`

Run from frontend: `node scripts/optimize-images.mjs /path/to/rabta-assets/hero`.
The originals are not committed. Generated AVIF/WebP assets and their measured dimensions and bytes are in `images/manifest.json`.

The requested docs/assets.md is outside this task's allowed paths; this file records the information within frontend ownership instead.
